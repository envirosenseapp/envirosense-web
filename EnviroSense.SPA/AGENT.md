This is an Angular project.

## UI rules
- use tailwindcss (https://tailwindcss.com/)
- use ng-zorro (https://ng.ant.design/)

## Structure rules
- every component is located in a dedicated folder
- use index.ts file for exporting types

## Angular Modules
There are 2 modules:
- `dashboard` module for actual dashboard for authenticated users.
  - Location: `src/app/modules/dashboard`
- `guest` module for guest users(unauthenticated). 
  - Location `src/app/modules/guest`
